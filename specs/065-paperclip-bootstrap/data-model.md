# Data Model: Bootstrap Anvil into Paperclip

**Phase**: 1 — Design & Contracts  
**Date**: 2026-07-05  
**Feature**: Bootstrap Anvil into Paperclip

## Overview

This feature models the Paperclip company structure for the Anvil project. The entities described here are Paperclip primitives (not anvil code entities) — they live in Paperclip's embedded Postgres database and are manipulated through the `npx paperclipai` CLI.

## Entity: PaperclipCompany

Represents the Anvil project within the Paperclip instance. Every Paperclip instance can host multiple companies.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Auto-generated by Paperclip |
| `name` | string | "Anvil" (fixed for this bootstrap) |
| `mission` | string | Project mission statement |
| `budgetMonthlyCents` | integer | Hard cap in cents (default: 7500 = $75/mo) |
| `status` | enum | active, paused, archived |

**Relationships**:
- Has many **PaperclipGoal** (goals tree from mission)
- Has many **PaperclipProject** (workstreams)
- Has many **PaperclipAgent** (employees)
- Has many **PaperclipIssue** (tickets)

**State transitions**: Active (seeded) → Paused (budget exhausted) → Archived (project wind-down)

---

## Entity: PaperclipGoal

Hierarchical objective under the company mission. Goals form a tree: mission-level → team-level.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Auto-generated |
| `level` | enum | `company` (mission-level) or `team` (sub-goal) |
| `title` | string | Short goal title |
| `description` | string | Detailed goal description |
| `parentId` | UUID (nullable) | Parent goal ID (for hierarchy) |
| `companyId` | UUID | Parent company |

**Relationships**:
- Belongs to **PaperclipCompany**
- Optionally has parent **PaperclipGoal** (team → company)
- Has many **PaperclipProject** (linked via goal-ids)
- Has many **PaperclipIssue** (traced to this goal)

**Validation**:
- Mission-level goal has no parent
- Team-level goal requires a parent (mission-level)

---

## Entity: PaperclipProject

A named workstream within the company, grouping related issues under one or more goals.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Auto-generated |
| `name` | string | Project display name |
| `description` | string | Project scope description |
| `goalIds` | UUID[] | Links to PaperclipGoal(s) |
| `companyId` | UUID | Parent company |

**Relationships**:
- Belongs to **PaperclipCompany**
- Linked to one or more **PaperclipGoal** (goal-ids)
- Has many **PaperclipIssue** (tickets for this project)

---

## Entity: PaperclipAgent

An AI employee with a role, budget, and adapter configuration.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Auto-generated |
| `name` | string | Display name (e.g., "Anvil CEO") |
| `role` | enum | `ceo`, `engineer`, `qa`, `designer`, `manager` |
| `title` | string | Human-readable title |
| `reportsTo` | UUID (nullable) | Manager agent ID (establishes hierarchy) |
| `capabilities` | text | Free-text job description |
| `adapterType` | enum | Always `opencode_local` for this bootstrap |
| `adapterConfig.model` | string | Primary model string |
| `adapterConfig.cwd` | string | Working directory (anvil repo path) |
| `runtimeConfig.modelProfiles` | object | Model profiles including "cheap" budget lane |
| `budgetMonthlyCents` | integer | Monthly spend ceiling in cents |
| `heartbeat.enabled` | boolean | Always `false` on creation (operator enables) |
| `companyId` | UUID | Parent company |

**Relationships**:
- Belongs to **PaperclipCompany**
- Optionally reports to parent **PaperclipAgent** (reportsTo)
- Assigned to many **PaperclipIssue** (assignee)

**Validation**:
- Adapter must be `opencode_local` for opencode_local adapter
- cwd must be a valid filesystem path
- Heartbeat created disabled (FR-006)
- Budget must not exceed company hard cap

---

## Entity: PaperclipIssue

A unit of work (ticket) assigned to an agent, linked to a project and goal.

| Field | Type | Description |
|-------|------|-------------|
| `identifier` | string | Auto-generated (e.g., "ANV-1") |
| `title` | string | Issue title |
| `description` | text | Detailed description |
| `priority` | enum | `high`, `medium`, `low` |
| `status` | enum | `open`, `in_progress`, `review`, `done`, `blocked` |
| `projectId` | UUID | Linked PaperclipProject |
| `goalId` | UUID | Linked PaperclipGoal |
| `assigneeAgentId` | UUID | Assigned PaperclipAgent |
| `companyId` | UUID | Parent company |

**Relationships**:
- Belongs to **PaperclipCompany**
- Belongs to **PaperclipProject**
- Belongs to **PaperclipGoal**
- Assigned to **PaperclipAgent** (assignee)

**State transitions**: `open → in_progress → review → done` (happy path) or `in_progress → blocked → open` (escalation)

---

## Entity: PaperclipWorkspace

A git worktree binding the anvil repository, enabling agents to create branches and PRs.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Auto-generated |
| `repoPath` | string | Absolute path to the anvil git repository |
| `companyId` | UUID | Parent company |

**Relationships**:
- Belongs to **PaperclipCompany**

---

## Entity Relationship Summary

```
PaperclipCompany (1)
  ├── PaperclipGoal (1 mission + 2 team = 3 total)
  │     └── PaperclipProject (4 total, linked to goals)
  │           └── PaperclipIssue (1 per project = 4 seed tickets)
  ├── PaperclipAgent (CEO + Platform Engineer + UX Engineer = 3 total)
  │     └── hierarchy: CEO ← Platform Engineer, CEO ← UX Engineer
  └── PaperclipWorkspace (1, binding anvil repo)
```

## Validation Rules (from spec)

| Rule | Source | Description |
|------|--------|-------------|
| ❌ Agents with heartbeats enabled at creation | FR-006 | Heartbeats MUST be disabled by default |
| ❌ Company without budget cap | FR-007 | Hard cap MUST be set |
| ❌ Missing paperclip health check | FR-012 | Script must verify Paperclip is running |
| ⚠️ Re-seeding without idempotency check | FR-009 | Script must detect existing company |
| ❌ Agent without cheap model profile | FR-013 | Budget lane profile required |
