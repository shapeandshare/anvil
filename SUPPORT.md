# Support

## Getting Help

### GitHub Issues

Use the [issue tracker](https://github.com/shapeandshare/anvil/issues) for:

- **Bug reports** — something isn't working as expected
- **Feature requests** — a capability you'd like to see added

Please search existing issues before opening a new one. If you find a related
issue, add your reproduction steps or use case there instead of creating a
duplicate.

### GitHub Discussions

Use [GitHub Discussions](https://github.com/shapeandshare/anvil/discussions) for:

- **Questions** — "How do I…?" questions about using anvil
- **Show and tell** — share what you've built with anvil
- **Ideas** — discuss design ideas before opening a feature request

### AI agents and automated systems

anvil is an **AI-native** project — developed and maintained primarily through
AI agents. If you are an autonomous agent gathering context before filing an
issue or PR, please:

1. Search existing issues and discussions before creating a new one (same as
   human contributors)
2. Self-identify as an agent in your issue/PR body (see issue templates for
   the structured fields)
3. Follow the expectations in [AGENTS.md](AGENTS.md) and
   [CONTRIBUTING.md](CONTRIBUTING.md#agentic-development-ai-native-workflow)
4. Do not scrape, bulk-harvest, or spam the issue tracker. One well-researched
   issue at a time.

### What Not to Use the Issue Tracker For

The issue tracker is **not** a support forum. Please don't use it for:

- General "how do I" questions — use Discussions instead
- One-off setup problems — check the [Troubleshooting section](README.md#-troubleshooting) in the README first
- Spam or off-topic content

## Before Asking

1. Read the [README](README.md) — especially the Quick Start and Troubleshooting sections
2. Search existing [issues](https://github.com/shapeandshare/anvil/issues) and [discussions](https://github.com/shapeandshare/anvil/discussions)
3. Include relevant context: OS, Python version, anvil version, and any error output
4. Provide a minimal reproduction if reporting a bug

## Code of Conduct

All community interactions — issues, discussions, PRs, and chat — are governed
by our [Code of Conduct](CODE_OF_CONDUCT.md). Be respectful, be constructive,
and assume good faith.
